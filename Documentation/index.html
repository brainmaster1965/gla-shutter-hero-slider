1. Overview & Key Features

Thank you for choosing the Gla Shutter Hero Slider! This component is a premium, highly performant, and responsive fullscreen hero slider designed for modern websites, landing pages, and templates.

🚀 100% Dependency-Free: This component is built strictly using modern Vanilla JavaScript and native CSS. It does not rely on jQuery, Swiper.js, or any third-party frameworks. You can integrate it directly into any environment without worrying about dependency conflicts or performance overhead.
  • Hide non desired elements: Progress timer on top (bar), nav-buttons & pagination-dots can be hidden via HTML data attributes (data-hide-progress, data-hide-navigation, data-hide-pagination)
  • Fullscreen Hero Experience: Perfectly scales across all desktop and mobile viewports with responsive image optimizations.
  • Shutter Reveal Transition: Smooth clip-path animations that transition between slides with professional flair.
  • Parallax Background Effect: Subtle scroll-driven movement adding depth to your imagery.
  • Modular Content Visibility: Toggle individual content elements (Author, Title, Topic, Description, Buttons) on or off per slide via JSON settings without altering HTML structure.
  • Dynamic 9-Grid Content Placement: Freely position slide content anywhere on screen (Top-Left, Center-Right, Bottom-Center, etc.) with precise alignment overrides.
  • JSON-Driven Content & Styling: Zero hardcoded text—manage all slides, typography, colors, borders, and button behavior dynamically from a central slides.json file.
  • Interactive Controls & Gestures: Features navigation arrows, dynamic pagination dots (optimized with robust neighbor-navigation & queue protection for v2.2.0), progress timer bar, global touch & desktop mouse drag-to-swipe support, and configurable stop-on-hover functionality.

3. Quick Start Integration Guide

  1. Copy the contents of the Main-Files folder into your web project directory.
  2. Link the unminified production stylesheet inside your HTML <head>: 
    <link rel="stylesheet" href="assets/css/style.css">
  3. Include the JavaScript engine right before the closing </body> tag: 
    <script src="assets/js/script.js"></script>
  4. Place the slider wrapper markup in your HTML body. Note: The slide items are automatically created and injected via JavaScript into the <div class="slide-list"></div> container based on your JSON configuration: 
    <div class="wp-block-gla-heroslider" data-autoplay="true" data-interval="7000" data-stop-on-hover="true">
    <div class="slide-list"></div>
    <div class="slide-arrows">
        <button id="prev">&lt;</button>
        <button id="next">&gt;</button>
    </div>
    <div class="slide-pagination"></div>
    <div class="slide-time"></div>
</div>

⚠️ Important Note on Local Testing (CORS Policy)

Because this slider loads content dynamically via JavaScript fetch() from slides.json, modern web browsers enforce security restrictions (CORS) when opening HTML files directly from your local hard drive (file:// protocol).

To test or run your project properly:

  • Use a local development server (e.g., VS Code Live Server extension, BrowserSync, or XAMPP/MAMP).
  • Or upload your files to a live hosting environment (like Netlify, Vercel, or your live web server).

5. Global Slider HTML Attributes

You can customize core behavior directly via HTML data attributes on the primary container element .wp-block-gla-heroslider:

Attribute Type Default Description
data-autoplay Boolean true Enables or disables automatic sliding (true or false).
data-interval Number 7000 Sets the autoplay duration between slides in milliseconds (e.g., 5000 = 5s).
data-stop-on-hover Boolean true Pauses autoplay when hovering over the slider. Can be set to false to keep autoplay running on hover.
data-hide-progress Boolean false Hides the top progress timer bar when set to true.
data-hide-navigation Boolean false Hides the left/right navigation arrows when set to true.
data-hide-pagination Boolean false Hides the bottom pagination dots when set to true.
